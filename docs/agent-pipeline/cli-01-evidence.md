This is the single funnel a port must reproduce: one numeric id per screen, one server-side element per id, one client-side element per id, and the client element only ever instantiated client-side.

### B. The shared container-screen framework

5. **The container screens share one construction and draw pattern, and their sizes cluster into four families.** Each screen's constructor calls the superclass with its container and binds a background texture; the `drawScreen` override calls the vanilla default background, then the superclass, then the hovered-tooltip helper, so tooltips work uniformly (`client/gui/GuiSmelter.java:19-29` shows the minimal form; the same trio appears at `client/gui/GuiPech.java:30-34`, `client/gui/GuiThaumatorium.java:60-64`, `client/gui/GuiGolemBuilder.java:88-92`, `client/gui/GuiVoidSiphon.java:52-56`, `client/gui/GuiPotionSprayer.java:39-43`, `client/gui/GuiArcaneBore.java:29-33`, `client/gui/GuiTurretBasic.java:28-32`, `client/gui/GuiHandMirror.java:26-30`). Ghost slots are the third shared convention: slots whose contents are a copy that the cursor never pays for, used by the seal filter grid (`common/container/slot/SlotGhost.java:7-17`; `common/golems/client/gui/SealBaseContainer.java:76-91`) and by the logistics board's filter grid (`common/container/ContainerLogistics.java:56`), with the full-stack variant beside them (`common/container/slot/SlotGhostFull.java:8-18`).

### C. The book's framework

8. **The browser is a draggable, wheel-zoomed camera over a two-dimensional research grid, with the camera smoothed and its position remembered between open and close.** The content area starts at a fixed sixteen-pixel inset and spans the window minus thirty-two on each axis (`client/gui/GuiResearchBrowser.java:106-107`, `:184-185`). A left-button drag inside that area pans the map by the mouse delta times the current zoom (`client/gui/GuiResearchBrowser.java:394-411`); the wheel steps the zoom by a quarter and clamps it between one and two (`client/gui/GuiResearchBrowser.java:428-436`); the pan target is clamped to the content bounds computed each refresh from the visible entries' grid positions (`client/gui/GuiResearchBrowser.java:245-265`, `:412-423`), and the drawn position eases toward the target each tick — a full step while within two pixels, then a fixed fraction of the remaining distance (the eighty-five-hundredths step) (`client/gui/GuiResearchBrowser.java:493-506`). The map position lives in two static fields written on close and read by the no-argument constructor, so reopening the book resumes where the camera was (`client/gui/GuiResearchBrowser.java:100-130`, `:294-299`); the statics start at the sentinel and are also what the coordinate-pair constructor overwrites when the page returns (`client/gui/GuiResearchBrowser.java:132-160`, `:1035-1042`), and a reopen whose remembered point falls outside the newly computed bounds recenters on the bounds midpoint (`client/gui/GuiResearchBrowser.java:301-314`).

9. **The grid is twenty-four pixels per cell, categories are side columns with their own gates, and the search field is a bottom-left overlay mode.** Each entry sits at its display column and row times twenty-four, with a thirty-two-pixel icon drawn at an eight-pixel offset from that point, hit-tested over a twenty-pixel box (`client/gui/GuiResearchBrowser.java:596-600`, `:664-666`); the content bounds are derived by shrinking to the minimum column or row and expanding to the maximum, minus a cell (`client/gui/GuiResearchBrowser.java:249-264`). The seven mod categories are listed down the left edge below the search button, and addon categories down the right edge at the window minus seventeen, each a sixteen-pixel icon button labelled with the localized category name and a completion ratio (`client/gui/GuiResearchBrowser.java:216-231`); the gates that decide which categories appear, and the count that feeds the ratio, are the progression lane's ([rsr-03-evidence.md](rsr-03-evidence.md) item 5) and are cross-referenced, not re-derived. When the right column overflows the window the browser adds a pair of up and down scroll buttons and an alignment nudge (`client/gui/GuiResearchBrowser.java:232-237`, `:869-876`). The search mode is entered from a button pinned at the window's bottom-left (`client/gui/GuiResearchBrowser.java:171`, `:859-868`), replaces the map with a results list drawn at a ten-pixel line pitch from y thirty-two, caps the typed string at fifteen characters, and prints a refine-your-search line when the list runs past the window (`client/gui/GuiResearchBrowser.java:173-183`, `:460-483`; the button and overflow keys at `assets/thaumcraft/lang/en_us.lang:1071-1072`).

10. **Three draw helpers are shared beyond the browser that defines them: the icon renderer, the forbidden glyph, and the custom tooltip.** The icon renderer is a public static routine that cycles an entry's icon list over time, handles three icon kinds — a texture, an item stack, and a focus reference — and takes a greyscale flag (`client/gui/GuiResearchBrowser.java:674-724`); the toast calls it for its own icon (`client/gui/ResearchToast.java:30`), and the focus branch delegates to the focal manipulator's node-drawing helper (`client/gui/GuiResearchBrowser.java:714-720` calling `client/gui/GuiFocalManipulator.java:653`), so a fix to either must be checked against both callers. The forbidden glyph — the warp warning drawn over an entry whose stages carry warp — is another public static (`client/gui/GuiResearchBrowser.java:1013-1020`; used for the icon state at `:602-604`, the semantics of the warp figure being [ply-01-evidence.md](ply-01-evidence.md)'s and the entry-content side [rsr-03-evidence.md](rsr-03-evidence.md)'s). The custom tooltip helper both screens use is the client utility library's (`client/lib/UtilsFX.java:326-330`; call sites at `client/gui/GuiResearchBrowser.java:796`, `:489`).

11. **The browser's click path is the tree's clearest request-then-open flow: the client asks the server, then opens locally either way.** On an unknown entry whose requisites pass, the click first sends the start-progress request packet, then opens the entry's page and shows a short popup naming it for three seconds; on a known entry it clears the two notification flags locally, tells the server to clear them, nudges the stage bookkeeping when the entry was fully read, and opens the page (`client/gui/GuiResearchBrowser.java:803-821`; the request machinery is [rsr-01-evidence.md](rsr-01-evidence.md) item 17's). A third branch walks the search results and routes categories, known entries, and recipe hits to their screens (`client/gui/GuiResearchBrowser.java:822-852`). The popup is drawn through the same custom tooltip helper while a deadline is in the future (`client/gui/GuiResearchBrowser.java:486-490`), and the line's message key is the one [rsr-03-evidence.md](rsr-03-evidence.md) item 34 records as absent from the language file — the capture records what actually renders (checklist T2). Escape and the inventory key close the screen back to the game (`client/gui/GuiResearchBrowser.java:316-325`).

12. **The page is a two-page spread with a keyboard and pointer paging model, a return stack for recipe drilldowns, and an escape ladder.** The pane is a fixed 256 by 181 region centered in the window and drawn scaled by 1.3 (`client/gui/GuiResearchPage.java:155-157`, `:260-272`); only the current page and the next are drawn, at the alternating spread sides (`client/gui/GuiResearchPage.java:277-285`), and the page cursor moves in steps of two inside a max-pages bound computed by the content parser (`client/gui/GuiResearchPage.java:1498-1514`; the parser itself is [rsr-03-evidence.md](rsr-03-evidence.md) item 12's). Paging is reachable from the arrow keys and page keys, and from a pair of drawn corner arrows hit-tested only while no recipe spread is shown (`client/gui/GuiResearchPage.java:1484-1489`, `:1616-1625`; the arrows' bob animation at `:290-299`). A static recipe stack backs the back action: clicking an ingredient pushes the current recipe and switches to the linked one, and the back key or the drawn return button pops (`client/gui/GuiResearchPage.java:1644-1651`, `:1626-1630`, `:1516-1525`), with a hover label on the return corner (`client/gui/GuiResearchPage.java:251-257`). The escape ladder: the first escape clears a recipe spread, an aspect insert, or the knowledge insert if any is open; otherwise it returns to the browser carrying the camera position back with the coordinate-pair constructor (`client/gui/GuiResearchPage.java:1470-1483`).
